## Long Description

```
StreamShōgun is a personal playlist player for Roku. Add your own M3U/M3U8 playlist URLs to browse and play your channels directly on your TV.

FEATURES:
• Add multiple M3U/M3U8 playlist URLs
• Verify playlist URLs before saving them
• Verify XMLTV EPG sources before saving them
• StreamShōgun account sign-in for Pro entitlement checks
• Pro support for unlimited playlist sources
• Pro EPG proxy support for compatible compressed guide sources
• Browse all playlists together or switch to a single playlist
• Manage and remove saved playlists from a TV-friendly settings screen
• Filter channels by playlist groups
• Search channels by name
• Save favorites and resume your last channel
• Quickly return to recently watched channels
• Full-screen HLS and MP4 video playback
• XMLTV programme guide support (EPG)
• Responsive guide loading for larger personal libraries
• Now/Next programme info per channel
• Dark theme optimized for TV viewing

HOW IT WORKS:
1. Open StreamShōgun and go to Library
2. Add your own playlist URL (M3U or M3U8 format)
3. Browse your channels by group or search by name
4. Select a channel to start watching
5. Save favorites and return to recent channels from the Library
6. Optionally add a verified XMLTV EPG source for programme guide data

PRIVACY:
Playlist and guide settings are stored locally on your Roku device. If you sign in to a StreamShōgun account, the app checks subscription entitlement with the StreamShōgun API. If you use the Pro EPG proxy, the app sends the user-entered EPG URL to the StreamShōgun API for decompression. No analytics or tracking. You can clear all data at any time from Settings.

StreamShōgun does not host or provide any content. Users add their own playlist URLs. Users are responsible for the content they access.
```

### Privacy Policy Template

If a standalone page is needed, use the following:

```
STREAMSHOGUN PRIVACY POLICY
Last updated: [DATE]

StreamShōgun ("the App") is a personal playlist player for Roku devices.

INFORMATION WE COLLECT
The App does not collect, store, or transmit any personal information.
Playlist URLs, EPG settings, and preferences are stored locally on
the user's Roku device using the Roku registry unless the user signs
in or uses a Pro proxy feature.

THIRD-PARTY SERVICES
The App does not integrate with third-party analytics, advertising,
or tracking services. When a user adds a playlist or EPG URL and the
App fetches data from that URL, it connects directly to the server
specified by the user. If the user signs in, the App connects to the
StreamShōgun API for account entitlement checks. If the user enables
the Pro EPG proxy, the user-entered EPG URL is sent to the
StreamShōgun API so compressed guide data can be fetched and returned
as XML.

DATA RETENTION
All data remains on the user's device. Users can clear all stored data
at any time via Settings > Clear All Data.

CONTENT DISCLAIMER
StreamShōgun does not host, provide, aggregate, or curate any media
content. All content accessed through the App is user-provided via
URLs that users enter themselves. Users are solely responsible for
ensuring they have the legal right to access any content.

CHILDREN'S PRIVACY
The App does not knowingly collect information from children under 13.

CONTACT
For questions about this privacy policy: support@streamshogun.com
```
