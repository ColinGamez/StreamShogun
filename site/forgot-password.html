Recovery Update

Password reset emails are retired.

StreamShōgun now uses Google-first sign-in instead of sending password reset emails. If you had an older password-based account, sign in with Google using the same email address and we’ll link it automatically.

If you still know your password, you can use the legacy login form. After you’re back in, you can decide whether to keep password login enabled for desktop fallback.

Best path: go to the login page, choose Google, and use the same email you used for StreamShōgun before.
