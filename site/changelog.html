v0.2.5 Latest November 8, 2026

Playback recovery

  • Playback stops waiting after a bounded startup or stall timeout and shows a recovery message.
  • Retry stream reloads the current channel without requiring you to switch channels.
  • Final playback errors distinguish access-denied responses, missing stream links, and unsupported media without exposing private stream details.
  • Playback timers are cleared when the player changes channels or closes.

Playback still depends on the availability and compatibility of your stream source.

Mac builds remain ad-hoc signed and not notarized. Apple Developer credentials are not configured for this release.

Local imports and first launch

  • Desktop playlist imports use a native file picker for M3U and M3U8 files, so the app receives the full file path instead of only a filename.

v0.2.3 November 8, 2026

Native Mac downloads

  • Separate native Intel and Apple Silicon DMG and ZIP downloads, with updates matched to your Mac's architecture.
  • Supports macOS 12 Monterey and later.

Window fixes

  • Clicking the Dock icon reopens the main window even while picture-in-picture is still playing.

  • Saved windows return to a connected display after an external monitor is disconnected.

Mac builds are ad-hoc signed and not notarized. Developer ID signing and notarization require Apple Developer credentials, which are not configured for this release.

v0.2.2 November 8, 2026

Library and guide fixes

  • Removing a playlist clears its channels while preserving channels shared with another playlist.
  • Repeated stream URLs no longer create duplicate channels during import.
  • Removing a browser guide restores overlapping programmes from remaining sources, including after restarting.
  • Empty desktop libraries clear stale channels. Failed deletions show an error and keep the library entry visible.

Accounts and reliability

  • Annual billing selection survives sign-in and registration, and checkout errors explain what went wrong.
  • Checkout reuses unfinished sessions and safely switches plans. Subscription activation verifies Stripe status and retries temporary failures.
  • Updated security dependencies and added installer, updater metadata, and packaged database checks.

Older browser guides saved without source ownership may need re-importing after deleting a guide. Desktop guide data remains in its local database.

v0.2.1 October 2026

New Features

  • requireString() / requireFiniteNumber() validators in IPC handler layer — applied to DB_SET_SETTING and DB_SAVE_WATCH for input safety
  • Discord reconnection backoff — 15-second cooldown between connection attempts prevents rapid retry spam
  • PIP param validation — openPipWindow throws on empty channelUrl; channelName falls back to "PIP"
  • <ErrorBoundary> component — class-based React boundary with retry button, wrapping all six page routes and the PIP player
  • Error boundary CSS (.error-boundary-*) in App.css

Improvements

  • IPC (main process) — Removed unused secureFetch() dead code; PLAYLIST_LOAD_URL now uses gzip-aware secureFetchText()
  • Scheduler — doRefresh() protected by a 60-second timeout guard to prevent stalling
  • Discord RPC — sendPacket checks socket.destroyed before writing; catches write errors and resets state
  • PIP window — closePipWindow() no longer double-nulls; cleanup deferred to the 'closed' event handler
  • Watch history DB — saveWatchSession runs inside a transaction and auto-prunes rows beyond 500
  • Store (Zustand) — Fire-and-forget calls in initFromDb now have .catch() guards
  • Player page — All async fire-and-forget calls wrapped with .catch() to prevent unhandled-rejection noise

Bug Fixes

  • PLAYLIST_LOAD_URL previously bypassed gzip decompression — now consistent with all other fetch paths
